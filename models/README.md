# Reference models

Parts for the default grid (60 × 40 mm, 130 mm deep, rail clearance 0.25 mm), generated by
`cad/build.py`. For a custom wall, add-ons or another clearance, use the builder.

- `stl/`: print-ready meshes, already in print orientation. Do not rotate or scale.
- `step/`: the same parts as editable solids in assembly orientation, plus `example_wall.step`.
- `reports/`: validation results, print check, parts list with filament mass, parameters used.
